# Support & Maintenance Services

Thank you for developing with GrowthScout AI. This document outlines support channels, issue trackers, and response time budgets.

---

## 1. Official Support Channels

### A. Technical Issues & Bug Reports
- Open a GitHub issue using our structured template: [GitHub Issues](https://github.com/pkmr3432/growthscout-ai/issues).
- Ensure you attach client trace logs and specify Python/Node versions.

### B. Security Disclosures
- Follow the instructions in [SECURITY.md](file:///Users/ptech/Desktop/growthscout-ai/SECURITY.md).
- Email **security@growthscout.ai** directly.

---

## 2. Response SLAs & Support Tiers

| Tier | Priority | Target Response | Target Resolution |
|:---|:---:|:---:|:---|
| **P1** | Severe outages, gateway unreachable, authentication failures | `< 1 hour` | `< 12 hours` |
| **P2** | Client SDK import problems, streaming disconnect loops | `< 4 hours` | `< 48 hours` |
| **P3** | Documentation drift, missing examples, minor layout bugs | `< 24 hours` | `< 7 days` |

---

## 3. Maintenance Policy
Minor version releases occur at the start of every sprint cycle. Patch releases carrying dependency security upgrades are deployed immediately upon container scan triggers.
